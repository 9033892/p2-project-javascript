Wat is het verschil met de script tag boven in te laden in de head tag t.o.v onder inladen aan het einde van je HTML tag?

Als de script tag boven in te laden is de browser kan het HTML-bestand tijdelijk stoppen met lezen totdat het script geladen en uitgevoerd is, daardoor kan de pagina trager zichtbaar worden.



Wat doet de attribuut defer in de script tag?

De attribuut defer zorgt ervoor dat het JavaScript-bestand al kan downloaden terwijl hij de HTML verder inleest



Wat is het verschil tussen HTML en JavaScript?

HTML zorgt voor de structuur en inhoud van een website en JavaScript zorgt ervoor dat een website interactief en dynamisch wordt.
